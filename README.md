# Car Price Prediction Using Linear Regression

## 1. Project Overview
This project predicts the selling price of a used car using Machine Learning. Linear Regression is used to estimate the car's selling price based on its details.

## 2. Objective
To build a Machine Learning model that predicts the selling price of a used car using its features.

## 3. Dataset
Datasetlink :- https://www.kaggle.com/code/vijayaadithyanvg/car-price-prediction-used-cars
Dataset: Car Price Prediction Dataset

The dataset contains the following columns:

- Car_Name
- Year
- Selling_Price
- Present_Price
- Driven_kms
- Fuel_Type
- Selling_type
- Transmission
- Owner

Target Variable: Selling_Price

## 4. Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## 5. Machine Learning Algorithm
Linear Regression

Linear Regression is a supervised Machine Learning algorithm used to predict continuous numerical values.

## 6. Project Workflow
1. Import required libraries.
2. Load the dataset.
3. Perform data inspection.
4. Check missing values and duplicate records.
5. Perform Exploratory Data Analysis (EDA).
6. Select input features and target variable.
7. Convert categorical data into numerical data using One-Hot Encoding.
8. Split the dataset into training and testing sets.
9. Train the Linear Regression model.
10. Predict car selling prices.
11. Evaluate model performance.
